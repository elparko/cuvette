# Test data sources

| File | Source | License |
| --- | --- | --- |
| ldl_chd.csv | R package MendelianRandomization 0.10.0, data `ldlc`, `ldlcse`, `chdlodds`, `chdloddsse`: summary statistics of 28 variants for LDL cholesterol and coronary heart disease, from Waterworth DM et al. 2010, Arteriosclerosis, Thrombosis, and Vascular Biology 30(11): 2264-2276, DOI 10.1161/atvbaha.109.201020. Published summary statistics, no data of persons. Written by data/make_fixtures.R. | GPL-2 or GPL-3, the license of the package |
| hdl_chd.csv | R package MendelianRandomization 0.10.0, data `hdlc`, `hdlcse`, `chdlodds`, `chdloddsse`: the same 28 variants for HDL cholesterol. Written by data/make_fixtures.R. | GPL-2 or GPL-3, the license of the package |
| calcium_glucose.csv | R package MendelianRandomization 0.10.0, data `calcium`, `calciumse`, `fastgluc`, `fastglucse`: 6 variants in the CASR gene region, from Burgess S et al. 2015, European Journal of Epidemiology 30(7): 543-552, DOI 10.1007/s10654-015-0011-z. Published summary statistics. Written by data/make_fixtures.R. | GPL-2 or GPL-3, the license of the package |
| calcium_correlation.csv | R package MendelianRandomization 0.10.0, data `calc.rho`: the correlation matrix of the 6 calcium variants. Written by data/make_fixtures.R. | GPL-2 or GPL-3, the license of the package |
