| File | Source | License |
| --- | --- | --- |
| sleep.csv | R data set `sleep` (Cushny and Peebles 1905, used by Student 1908), from https://vincentarelbundock.github.io/Rdatasets/csv/datasets/sleep.csv. The SHA-256 matches bench/papers/student1908-sleep/fetch.sh. | Historic published measurements, public domain in effect. The Rdatasets collection is GPL-3 (bench/papers/student1908-sleep/paper.md). |
| sleepstudy.csv | R package lme4, data set `sleepstudy` (Belenky et al. 2003), from https://vincentarelbundock.github.io/Rdatasets/csv/lme4/sleepstudy.csv. The SHA-256 matches bench/papers/belenky2003-sleepstudy/fetch.sh. | GPL-2 or later, the lme4 package license (bench/papers/bates2015-lme4-sleepstudy/paper.md) |
| rossi.csv | Rossi, Berk and Lenihan 1980 recidivism data, file `lifelines/datasets/rossi.csv` of lifelines, https://github.com/CamDavidsonPilon/lifelines. The SHA-256 (0214400170e07f30...) matches the copy on the master branch, checked on 2026-10-08. The same data are in the R package carData. | MIT, Copyright (c) 2017 Cameron Davidson-Pilon (lifelines LICENSE). Keep the notice. Cite Rossi, Berk and Lenihan (1980). |
| plantgrowth.csv | R data set `PlantGrowth` (package datasets; Dobson 1983, Table 7.1), from https://vincentarelbundock.github.io/Rdatasets/csv/datasets/PlantGrowth.csv. The SHA-256 (d1738e182d566ed0...) matches that file, checked on 2026-10-08. | GPL-2 or GPL-3, the license of R and its datasets package. Rdatasets keeps the license of the source package. |
| warpbreaks.csv | R data set `warpbreaks` (package datasets; Tippett 1950, "Technological Applications of Statistics"), written with `write.csv(warpbreaks)` in R 4.6.1. | GPL-2 or GPL-3, the license of R and its datasets package. |
| rounding_times.csv | The `RoundingTimes` matrix of the R `friedman.test` help page, from Hollander and Wolfe (1973), "Nonparametric Statistical Methods", page 140. One row for each player and method. | GPL-2 or GPL-3, the license of R. The numbers are published measurements from 1973. |
| hollander_depression.csv | The depression data of the R `wilcox.test` help page, from Hollander and Wolfe (1973), page 29. Nine patients, first and second measurement. | GPL-2 or GPL-3, the license of R. The numbers are published measurements from 1973. |
| hollander_permeability.csv | The permeability constants of the R `wilcox.test` help page, from Hollander and Wolfe (1973), page 69. Ten treated and five control samples. | GPL-2 or GPL-3, the license of R. The numbers are published measurements from 1973. |
