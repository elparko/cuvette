# Production audit, 15 October 2026

Branch `audit-prod`, based on `main` 0d6b8c33 (round 7 and round 8 fixes).
Six read-only auditors (Sonnet) covered six areas. Sonnet workers fixed the findings
in two phases. A reviewer read every branch before its merge, and the full diff twice.

## What changed

Safety
- Every adapter child, hook, MCP server and locate command now runs with `withoutSecrets`.
  `{env:NAME}` resolves a fixed safe set (HOME, PATH, ...) or a name in the new `pass_env`
  manifest list. A secret-pattern name never resolves. `cuvette adapter check` warns on it.
- `localUrl` accepts a LAN address only as a full IPv4 literal. `10.evil.example.com` now gets the patient-data card.
- The OpenAI key goes only to api.openai.com, a local address, or a host in the user setting
  `openai_key_hosts`.
- "Always allow" is not offered for `run_command`, `write_file`, `search_literature` and `eln_push`.
  The server, the card layer and the session each refuse it.
- Hooks run detached, die as a process group, have a 64 KB output cap, and block the action
  on a timeout or a spawn error (PreToolUse only).
- `read_file` refuses secret files (`.env`, `.netrc`, keys). `screenshot` asks before it runs.
- The Seatbelt and bwrap sandbox profiles deny reads of `open.json` (it holds the window token). The `unshare` fallback does not.
- After a script or adapter exits, its process group is killed.
- Built assets are served before the token check again; `sendAsset` refuses paths outside `ui-dist/assets`. `/api/thumb` checks the file root. `allowedFile` refuses secret files. Unexpected errors return
  500 with a plain message. The ntfy notify URL must be https (or http on this computer) and no longer carries the token.
- The desktop app opens only http, https and mailto links, watches the core process, and
  rejects IPC calls from a page that is not the core page. The web page has a Content Security Policy.
- `/open` refuses files with an executable extension, and files without an extension that have an executable bit.
- MCP results, HTTP bodies and images are capped at 16 MB. `read_table` reads at most 8 MB.
  `list_files` with a pattern that walks folders stops at 2000 entries. `call_timeout_s` must be 1 to 86400.
- A remote MCP server's `readOnlyHint` is ignored; the manifest `read_only` mark decides.

Data integrity
- `writeFileAtomic` (temp file plus rename) for settings, access, installed adapters, methods,
  questions, blob copies and `.ref.json`. Torn files are moved aside with one notice.
- Bad lines in `changes.jsonl` are skipped. The adapter update moves the old folder aside first and
  restores it on failure. `removeInstalled` refuses the adapters folder itself.
- The home folder is created 0o700; session folders 0o700; `log.jsonl`, questions and crash files 0o600.
- `spend.jsonl` follows `CUVETTE_HOME`. A failed spend append keeps the reply.

Agent loop
- At most 16 tool calls per reply; parallel read-only calls run four at a time.
- `busy` clears only after the report and the Stop hook.
- The session record stores the Cuvette version, model, max_tokens, effort and a sha256 of the
  system prompt; a new entry records each change of the prompt.
- The helper agent's tokens count in `/usage`. Its prompt marks file content as data.
- Logs over 256 MB are read in part and marked "log too large to read".
- `uncaughtException` and `unhandledRejection` close open sessions, write `crash-<time>.log`
  and exit with code 70.

Release and CI
- All GitHub actions are pinned by commit SHA. `test.yml` has `permissions: contents: read`.
- CI builds the bundle and the web UI and runs `node dist/cli.js --version` and `npm pack --dry-run`.
- A macOS job runs the suite and `cargo test`. Dependabot covers npm (root and desktop), actions and cargo.
- `release.yml` (tag `v*`): version check, desktop build, npm publish with provenance, GitHub release.
- `bin/cuvette.js` refuses Node older than 22 with a plain message.

Test harness
- `vitest.config.ts`: pool forks, 4 workers, longer timeouts, one web UI build in `globalSetup`.
- Wall-clock assertions use `withinMs`, which skips with a notice when the machine is loaded, and
  each such test also asserts an end state.
- `app-a11y` is split into five files. The suite runs in about 5 minutes; before, the default run
  did not finish in 25 minutes.

## Not done here (Parker's decisions)

- `package.json` `files`: add CITATION.cff, CREDITS.md, DATA_LICENSES.md, LICENSES/ and negations for
  fetched data folders; README note on `npm run ui:build`. These files belong to the `pkgdata` branch.
- Code signing and notarization of the desktop app; the `NPM_TOKEN` secret.
- A default per-turn dollar cap. Proxy support (needs an SDK upgrade). A Windows sandbox for `run_script`.
- An `.env.example` file and a public `.pem` certificate count as secret files for `read_file`.
