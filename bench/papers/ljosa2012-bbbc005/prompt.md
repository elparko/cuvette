# Prompts

## Plain requests
1. These are fluorescence images of cells with different focus. Count the cells in the sharp ones and tell me if my counts match the numbers in the file names.
2. How badly does blur change the cell count? Use the nuclei images in this folder.
3. Pick the 600 sharpest nuclei images and give me counts per image and one summary number for how accurate they are.

## Guided variant
Question: How does image blur change the accuracy of automatic nucleus counting on the BBBC005 synthetic set, compared with the true counts in the file names?
