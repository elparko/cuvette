# Prompts

## Plain
1. I have a small set of aligned sequencing reads and the reference they were aligned to. How many reads mapped, and how many are properly paired?
2. Sort and index my alignments so I can open them in a viewer.
3. How many reads fall on the second reference sequence between positions 100 and 200?

## Guided
How well did these paired reads align to the reference, and how are they spread across the two reference sequences?
