# Prompts

## Plain
1. I have 17 DNA sequences already aligned in a PHYLIP file. Which evolutionary model fits them best?
2. Build the tree for these sequences and tell me how sure you are about its branches.
3. I also have 6 raw sequences in a FASTA file. Line them up and tell me how long the alignment is.

## Guided variant
Question: What is the best-fit substitution model and the maximum-likelihood tree, with branch support, for the 17 mitochondrial sequences in example.phy? Use the model chosen by the data, and report the log-likelihood.
