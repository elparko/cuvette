# Prompts

## Plain
1. I ran a blood sample spiked with a few standards at two concentrations, three injections each. Find the compounds that differ between the two levels.
2. How many features do you see in the first low-concentration file?
3. Which of the changed features can you name from a metabolite database?

## Guided
Which metabolite features differ between a low and a high spike-in level in triplicate LC-MS runs, and can they be matched to known compounds?
