# Prompts

## Plain
1. I have mIPSC recordings from 32 Purkinje cells, 16 control and 16 conditional knockout, from 12 mice. Does the knockout change the frequency or the amplitude of the events?
2. Does it change the rise or the decay time?

## Guided
The files are Igor Pro packed experiments with no unit in the waves. Detect the events with a scaled template in each cell, skip the test pulse at the start of each sweep, and compare the cell values between the groups. Say how many animals each group has.
