# Prompts

## Plain requests
1. I have 200 microscope images of cell nuclei in a folder. Count the nuclei in each image and give me a table.
2. Find the nuclei in these images and tell me how well the automatic outlines match the hand-drawn ones in the masks folder.
3. Take the 50 test images listed in the metadata folder. Segment the nuclei and report how many I miss compared with the hand annotation.

## Guided variant
Question: Can a standard CellProfiler nucleus pipeline find the nuclei in the BBBC039 U2OS image set about as well as the published classical baseline, scored against the expert masks on the test split?
