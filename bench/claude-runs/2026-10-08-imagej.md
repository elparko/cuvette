**Manual route for each step**

1. Open the image:
   - Select File > Open... and open `catalog/imagej/data/blobs.gif`.
   - Select Image > Show Info... to see the size, bit depth and scale. The result is 256 × 254 pixels, 8-bit, with no scale.
   - Macro: `open("/Users/parker/Code/guided-analysis/catalog/imagej/data/blobs.gif");`
2. Threshold:
   - In Process > Binary > Options..., clear Black background.
   - Open Image > Adjust > Threshold..., set the method to Default and set Dark background to off.
   - Click Auto, then close the window. Do not click Apply.
   - Select Process > Binary > Convert to Mask.
   - Macro: `setAutoThreshold("Default"); run("Convert to Mask");`
3. Count the particles:
   - In Analyze > Set Measurements..., select Area, Mean, StdDev, Min/Max, Centroid, Perimeter, Shape descriptors, Integrated density and Median. Set Redirect to None.
   - Open Analyze > Analyze Particles... and set Size to 0-Infinity, Circularity to 0.00-1.00 and Show to Outlines.
   - Turn on Display results, Clear results and Exclude on edges, then click OK.
   - Macro: `run("Analyze Particles...", "size=0-Infinity circularity=0.00-1.00 show=Outlines display clear exclude");`
