# Instructions for agents

Read [CLAUDE.md](CLAUDE.md). It has the text rules for this repository.

In short: all text uses ASD-STE100 Simplified Technical English (STE).
Instructions have 20 words or fewer, descriptions 25 or fewer.
Use the active voice and "must" for a requirement.
Do not write "e.g.", "i.e.", "etc." or "and/or", and write no marketing filler.
Expand each acronym the first time you use it.
Run `npm run lint:text` before you commit a change to the docs or UI text.
